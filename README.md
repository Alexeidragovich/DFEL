# نظام إدارة الجنائيات الرقمية وسلسلة الحيازة (Digital Forensics Evidence Locker)

نظام متكامل واحترافي لإدارة الأدلة الرقمية الجنائية وتتبع سلسلة الحيازة (Chain of Custody) والتحقق من النزاهة الرقمية للأدلة عن طريق خوارزميات التشفير (MD5 & SHA-256).

---

## 🌟 المميزات الرئيسية

- **التحقق من النزاهة الرقمية (Cryptographic Integrity):**
  - حساب مصفوفات التشفير (MD5 & SHA-256) تلقائيًا عند رفع أي دليل.
  - زر خاص لـ **فحص النزاهة الفوري** وإعادة حساب الـ Hash لمقارنته بالقيم الأصلية للتأكد من عدم التلاعب بالملف.

- **تتبع سلسلة الحيازة (Chain of Custody Log):**
  - تسجيل دقيق لجميع تنقلات الدليل الرقمي (الجمع، النقل، الفحص، التخزين، التسليم، الإتلاف).
  - توثيق طرفي النقل (من / إلى)، الموقع، والتاريخ والوقت.

- **الرسم البياني التفاعلي للعلاقات (Interactive Evidence Graph):**
  - عرض شبكي تفاعلي باستخدام مكتبة `vis-network` يربط الأدلة والتحقيقات ببعضها البعض.
  - تحديد نسبة الثقة (Confidence Level) ونوع العلاقة (يحتوي، مشتق من، تواصل مع، تم تنفيذه على، إلخ).

- **لوحة التحليلات والإحصائيات (Analytics Dashboard):**
  - رسوم بيانية تفاعلية بواسطة `Recharts` لاستعراض توزيع الأدلة حسب النوع (ملفات، سجلات، بريد، ذاكرة، شبكات، إلخ).
  - إحصائيات مستمرة حول عدد القضايا المغلقة والمفتوحة والأدلة المصدقة.

- **تصدير التقارير وسجلات المراجعة (Audit & Export):**
  - تصدير كشوفات الأدلة بصيغة CSV.
  - طباعة وتوليد تقارير القضايا بأسلوب مُجهز للطباعة والتصدير كـ PDF.
  - سجل مراجعة (Audit Trail) كامل لجميع أنشطة النظام.

- **دعم كامل للغتين العربية والإنجليزية (Bilingual RTL / LTR):**
  - تبديل فوري ومباشر بين الواجهة العربية (RTL) والإنجليزية (LTR).
  - تخصيص المصطلحات الجنائية والتنبيهات بدقة عالية.

- **دعم النمط الداكن والفاتح (Dark / Light Theme):**
  - واجهة حديثة بأسلوب السيبرانيات والجنائيات الرقمية مع إمكانية التبديل بين الوضع المظلم والواضح.

## 🚀 التقنيات المستخدمة

- **الواجهة الأمامية (Frontend):**
  - React 19 + TypeScript
  - Vite
  - Tailwind CSS v4
  - Lucide React (الأيقونات)
  - Recharts (الرسوم البيانية)
  - Vis-Network (شبكة العلاقات التفاعلية)

- **الخلفية (Backend):**
  - Node.js + Express
  - Multer (لرفع واستقبال الملفات الجنائية)
  - Crypto (لحساب التوقيعات الرقمية MD5 و SHA-256)
  - ESBuild & TSX

## 🛠️ التشغيل والتثبيت

### 1. تثبيت الحزم (Dependencies)
```bash
npm install
```

### 2. تشغيل بيئة التطوير (Development Mode)
```bash
npm run dev
```
سيعمل الخادم والموقع على المنفذ المحلي: `http://localhost:3000`

### 3. الفحص البرمجي (Linting)
```bash
npm run lint
```

### 4. بناء المشروع للإنتاج (Production Build)
```bash
npm run build
npm run start
```

## 🔒 الأمان والنزاهة
تم تصميم هذا النظام للالتزام بالمعايير الجنائية في الحفاظ على الحجية القضائية للأدلة الرقمية، حيث لا يتم تعديل الملف الأصلي إطلاقًا، وتؤكد خوارزمية SHA-256 سلامة الملف وحمايته من التغيير طوال دورة حياة التحقيق.
